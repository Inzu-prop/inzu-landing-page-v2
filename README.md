# Inzu — Property Management Landing Page

Marketing landing page for [Inzu](https://inzu.co), an AI-powered property management platform for Kenyan landlords.

## Tech Stack

React 19 · Vite 6 · Tailwind CSS v4 · Motion v12 · React Router v7

## Getting Started

```bash
npm install
npm run dev        # http://localhost:3000
```

## Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | TypeScript type-check |
| `npm run clean` | Remove `dist/` |

## Deployment

Deployed on Vercel. SPA routing handled via `vercel.json` rewrite rule.
